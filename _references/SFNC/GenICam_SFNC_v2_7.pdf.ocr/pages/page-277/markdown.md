### 11.2.15 EncoderResolution

|  Name | EncoderResolution[EncoderSelector]  |
| --- | --- |
|  Category | EncoderControl  |
|  Level | Optional  |
|  Interface | IFloat  |
|  Access | Read/Write  |
|  Unit | mm  |
|  Visibility | Expert  |
|  Values | -  |

Defines the resolution of one encoder step.

Note: The recommended unit is mm but other units can be used if required.
