### 17.5 SequencerMode

|  Name | SequencerMode  |
| --- | --- |
|  Category | SequencerControl  |
|  Level | Recommended  |
|  Interface | IEnumeration  |
|  Access | Read/Write  |
|  Unit | -  |
|  Visibility | Expert  |
|  Values | On Off  |

Controls if the sequencer mechanism is active.

Possible values are:

- Off: Disables the sequencer.
- On: Enables the sequencer.
